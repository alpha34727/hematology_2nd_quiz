# Hematology II — 血液學二段疾病圖譜

血液學二段（白血球、造血、白血病、MDS/MPN、淋巴／漿細胞腫瘤、HSCT）的疾病分類心智圖，並標註 105、109、110 年考古題的重點。

**線上版：<https://alpha34727.github.io/hematology_2nd_quiz/>**

## 功能
- 心智圖／清單兩種檢視；點到疾病可看概要、成因、症狀、檢驗、治療、預後
- 考古題標註：分類旁的「考 N」標籤、內文黃色螢光關鍵字、疾病頁的考古題區塊
- 依年份篩選、只看考過的分類；搜尋疾病、基因、標記、藥物或題目文字
- 「考前重點」分頁：整理 11/02 課程總結（含影片中游標停留位置）與各次逐字稿中老師提到的考點——考／不考一覽、老師原話、各疾病比較表、逐張時間軸、快問快答；最前面另有 9/28〈Structure and Functions of WBC〉的「白血球構造與功能」三區（顆粒球、單核球／巨噬細胞、淋巴球與效應細胞）
- 淺色／深色模式；手機可用

純靜態網頁（HTML / CSS / JavaScript），不需要建置，直接開 `index.html` 即可。

## 檔案
| 路徑 | 內容 |
|---|---|
| `index.html`, `css/`, `js/` | 網頁本體 |
| `js/data.js` | 所有疾病內容（專有名詞用英文） |
| `js/exams.js` | 考古題（由腳本產生，請勿手動修改） |
| `js/focus-data.js`, `js/focus-wbc.js`, `js/focus.js` | 「考前重點」分頁的內容與畫面（`focus-wbc.js`＝9/28 白血球構造與功能） |
| `tools/exam-map.js` | 考古題 → 疾病節點的對應表與標註關鍵字 |
| `tools/build-exams.js` | `node tools/build-exams.js <考古題.json>` 重新產生 `js/exams.js`，並檢查關鍵字是否存在 |
